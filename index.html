✏️ MSDS 직접입력 분석

CAS번호와 함량을 직접 입력하여 화관법(K-REACH) · 산안법(KOSHA) 규제 여부를 즉시 조회합니다.

화평법 K-REACH 산업안전보건법 KOSHA 유해화학물질 판정 금지·특별관리물질
API 간단 사용법

사이트 주소 뒤에 아래 경로를 붙여 GET 요청을 보내면 JSON 결과를 받습니다.

K-REACH · 함량별 규제 조회 /api/kreach?cas=96-29-7&contentMax=25&isLt=false

cas: CAS번호 · contentMax: 최대함량(25% → 25)
isLt: 이하(≤)는 false, 미만(<)은 true

KOSHA · 산안법 조회 /api/kosha?cas=96-29-7

응답의 success로 조회 성공 여부를 확인하고, regulations에서 규제 목록을 읽습니다. K-REACH의 matchedByContent가 true이면 입력 함량에서 해당합니다.

엑셀 연동: CAS번호·최대함량을 표(Ctrl+T)로 만든 뒤 Power Query에서 각 행의 값을 위 매개변수로 보내세요. 데이터 → 모두 새로 고침으로 재조회합니다.

최종 구매 판정에는 KOSHA와 사내 허가목록 확인도 필요합니다.

LLM 프롬프트

첨부한 MSDS PDF(또는 캡처 이미지)를 기준으로,
각 MSDS마다 [CAS NO | 최소함량 | 최대함량] 정보만 추출해 테이블을 생성하라.

조건:

  • 열 헤더([CAS NO | 최소함량 | 최대함량])는 출력하지 말 것
  • 테이블 상단에 MSDS 제목을 1회 출력 후 줄바꿈
  • 각 성분은 한 줄씩 출력
  • 하나의 MSDS가 끝나면 공백 1줄 추가
  • 결과 전체를 CSV 코드 형식으로 출력할 것
  • 함량은 % 기호 없이 숫자만 사용 (예: 0.1~1 → 0.1,1)
